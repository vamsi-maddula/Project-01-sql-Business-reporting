# Project 01: SQL Business Reporting and KPI Analysis

Overview
This project demonstrates end-to-end SQL analytics and business reporting using a realistic #retail sales dataset (1,200+ rows).  
It focuses on revenue analysis, customer behavior, product performance, KPI calculation, data quality validation, and reconciliation checks, structured as a   #GitHub ready analytics project

The project mirrors how SQL is used in real-world business intelligence and reporting teams.


# Business Problem
A retail company operates across multiple regions and sells electronics and accessories.  
Business stakeholders want answers to the following:

- How is revenue trending over time?
- Which customers and products drive the most revenue and profit?
- Are margins healthy across categories?
- Are KPIs consistent and reliable?
- Is the data clean and financially accurate enough for reporting?


 # Objectives
- Build business-focused SQL reports
- Calculate executive-level KPIs
- Analyze customer and product performance
- Perform time-series analysis (MoM growth, rolling averages)
- Validate data quality and financial integrity
- Produce dashboard-ready outputs for BI tools like Power BI
